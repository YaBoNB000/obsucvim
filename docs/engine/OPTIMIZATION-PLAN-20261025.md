## 2. 批次 1（已实施，源码已改）

### 2.1 V-06 / V-07：诱饵与惰性局部

`engine/src/vmgen/v15.rs` 新增 `idle_val` / `idle_local`，把四处"常量死码"生成点
（chunk 解码器 `qc`/`qr`、KSUM 载体 `qf`、filler `qn`、LCG 步进 `qv`）改为：

```
形态 0：({probe}~=nil)and A or B
形态 1：(B)+(if {probe}==nil then 0 else A-B)
形态 2：(({probe}~=nil)and A or B)
形态 3：(B)+(({probe}~=nil)and(A-B)or 0)
局部形态：plain / if-else 后置 / 先 B 后条件覆盖 / do 块临时量
```

`probe` 取运行期状态表槽位（`C[sumslot]` / `C[idx]` / `s`），值本身不被任何后续代码消费，
因此语义中性；但**静态侧再也拿不到"字面量→字面量"的可折叠式**。

### 2.2 V-08：噪声去可折叠

`engine/src/junk.rs` 重写：噪声数值改为 `常量 ± #"随机字面量"` 与 `x % m + n`，
分支条件改为运行期余数比较（两侧均赋值，语义中性）。旧的
`if b*b>=0 then …`、`local d=(b+1)-1` 形态全部消失。

### 2.3 负面实证（同源码同 seed，2026-10-25 实测）

样本：`artifacts/targets/R064_7kb_src.lua`，`--preset v15 --env-check --bind-executor --seed 20261025`。

| 指标（静态正则/计数，不执行 Lua） | 改动前 | 改动后 |
| --- | --- | --- |
| 诱饵同签名 `[N]~=nil and A or B` | 95 | 25（槽位/形态已轮换，无统一锚点） |
| 常量三元 `if X>=N then A else B` | 39 | 1 |
| 恒真条件 `*x>=0` | 27 | 0 |
| 恒等 `+N-1` | 28 | 1（非噪声语料内） |
| 体积 | 354,533 B | 353,846 B（**略降**，非纯体积） |

语义回归：`engine/tests/run_tests.sh` 非 VM 相位 **37/37 通过**（37 个语料 × luau）；
VM 相位 37 项失败为**既有缺陷**（见 §4），改动前后一致。

## 3. 批次 2/3 方案（未实施，逐条过筛后待批）

### 3.1 V-01 载体层静态可解

问题：`R[78]`/`R[73]` 的 base94 载体 + 常量表 + 三阶 LCG，密钥全部是产物内字面量。

候选形态与过筛：

- **(a) 双车道互锁**：两段载体互为对方的密钥源（A 的先导块给 B 的基，B 的解出块给 A 的
  步长），静态侧仍需同时解两段。→ R5✓（真实参与解码）R9 可证（拔掉任一段即解错）；
  但 R2✗（两段都需先解一段，仍是必经点）。
- **(b) 片段置换 + 惰性解**：仅在**被执行的 chunk** 到达时才解下一片，未执行的片永远
  保持密文。→ R5✓ R2✓（无单一解码器）R9 可证（未执行分支的片字节仍为密文，可直接取证）。
- **(c) 全量随机置换**：把 360 B 的载体拆成 N 片，喂给不同 shard。→ 与 (b) 合并做。

结论：批次 2 采用 **(b)+(c)**；(a) 只作为其中一种 shard 内部形态。**不满足 R2 的版本不入清单**。

### 3.2 V-03 运行时秘密入钥流（与 V-01 合并）

要求（缺一不可）：

1. 探针值进钥流：`k = f(probe_delta, 静态材料)`，且 probe_delta 参与**多轮**运算
   （不是一次 XOR）；
2. 失败形态是**错钥静默**（解出垃圾 → 后续自然崩），不得新增固定错误文案（R4）；
3. 至少有 **2 个独立熵源**（executor API 存在性 + 宿主表结构指纹），避免 R3 单点；
4. 必须给负面实证：`--fake-host` 桩件 → 解不出正确产物的比例 = 100%。

风险：R2（探针是必经点）。缓解：探针结论**只调参不判门**——不同探针结果落到不同
shard 参数，缺一个仍能继续（只是解错），从而不形成"过/不过"的二元咽喉。

### 3.3 V-02 密钥材料去可折叠（可独立先做）

- 禁止 `264998881-92467504` 这类"两常量之差"直接发射；
- 改为：常量存放在两张不相邻表的随机槽位，运行期按 shard 编号取回并拼接，
  拼接线本身吃一个运行期量（如 shard 索引）；
- 过筛：R1✓ R2✓（不新增单一取用点，取值散在 shard 内）R3✓ R4✓ R5✓（参与解码）
  R6✓（槽位/表序跨 seed 变）R7✓（纯算术，无宿主依赖）R8✓（一次性，无循环开销）
  R9✓（常量折叠脚本在本轮即可作为回归器：折叠后不得改变产物语义）。

### 3.4 V-04 / V-05 语义表与原语表

- 语义串（35 处字符码调用）→ 分片到多个 shard，按 chunk 需求惰性拼装；
- 原语表（`bit32.bxor` 等）→ 键位随机化 + 两表交叉（A 存 key，B 存 value，索引错位）；
- 约束：不得引入"唯一装配函数"（R2）；装配点必须分散在已有 shard 内。
