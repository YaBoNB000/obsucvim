# Lura15 可采纳/改进点盘点（2026-09-25）

> 基于 `docs/redteam/redteam-luraph15-breakout.md` 全量（含 §10 续战）对真实 Luraph v15.0（171K）的逆向实证，逐条盘点“它有什么、我们有没有、要不要学、怎么学”。**诚实原则：不夸大我方、不回避差距**。

---

## 1. 总览雷达图

| 维度 | 真 Luraph v15 | 我方 v15 现役 | 结论 |
|---|---|---|---|
| 解释器可见性 | 明文 32KB+3KB（致命弱点，30 分钟全文提取） | **全入密**（43 handler + parse + dispatch 加密） | **我方领先**，坚守不动摇 |
| 分派模型 | 4 表 × 运行期切换（S∈{251,99,8,140}） | 单表（251） | **差距**，高优先级可学 |
| 快照对抗 | 3 处自变形（`J[Q]=12/58` 等）+ 指令覆盖式演化 | 仅 `J[Q]=12` 单点 | **差距**，可学 |
| 常量隐藏 | 4 代理表懒解密 + 跨表依赖 + 状态化演化 | 掩码数组 + 单表查表 (`raw[0]` 直读) | **差距**，高优先级可学 |
| 块解密 | 每槽位钥匙自含 + 惰性按块 + 自修改 | 块 SALT + 链哈希 + 单块 LCG | 思想同源，粒度可加密 |
| 数组复用 | `J` 在 S==8 时作操作数（角色复用） | 固定角色（J=opcode） | **差距**，中优先级 |
| 环境绑定 | 极简 2 槽（Vector3/Vector2 构造即死，无分支） | 去中心化 4 槽 + 语义探针 + 毒药循环 | **我方更重**，可借鉴其极简形态作诱饵层 |
| 反调试 | 0 明文，`debug` 串藏闭包环境 + 话术伪装 | 探针钥匙化 + 计时守卫 + 执行器认证 | **我方更深**，可学话术伪装 |
| 载体保护 | LPH 水印 + 10 字符转义（32 命中） | base94 + LCG 掩码 + 分片 | **我方领先** |
| 混淆技巧 | x/xC/xL 命名 + 阈值树 + 条件表达式 | 状态寄存器随机 + 变体 handler | 持平，命名体系可借鉴 |

**一句话**：真 v15 赢在“结构复杂度 × 状态化演化”，输在“全部明文”；我方赢在“加密深度 × 运行期绑定”，输在“分派单一 × 常量池直读”。

## 4. 落地路线图（最小可验证增量）

### 增量 S1：四表派发（2 周）

1. `compiler.rs` 新增 `S` 状态（0..3 映射 251/99/8/140），`block_starts` 分四桶；
2. `template.rs` 解释器 `if S==` 四段，`fetch` 改 `J/y/R` 三源（复用 `trace_gen` 逻辑）；
3. `isa.rs` 四套 `OCt`（`OC251/OC99/OC8/OC140`），`dispatch_tree` 四棵；
4. 验证：`trace_gen` 2000 步重放一致 + `v15_fingerprint` 32/32 带宽内 + `multiseed` 0。

### 增量 S2：代理表常量池（1.5 周，依赖 S1 的 `__index` 形态）

1. `compiler::finish` 常量池改为 `raw[0]` 密文 + 代理表 `setmetatable` 发射；
2. `BSS`/`RT` 双侧 `__index` 用现役 `fold4` + `rawset` 缓存，跨代理异或（A3）同入；
3. `tests/attack_constants.py` 改搜代理表 `pairs`（应 0）+ `rawget`（应 nil）；
4. 验证：`after.log` 演化测试（`t[1]` 前后异值）+ `faithful_stub` 4/4。

### 增量 S3：覆盖式演化（1 周，复用 S2 的 `raw[0]` 覆盖）

1. 块解密后对 `R/m` 同步 `J[Q]=new` 覆盖；
2. `__index` 内 `raw[0][k] = new` 覆盖式演化；
3. 验证：`plain k=11:5,16,48` 快照对比 + `t[2058] f→banner` 时序复现。

> 三增量可独立回退（`--preset v15` 关 S1 即回单表），与 `IronBrew2` 的 `--bind-executor` 开关正交。

## 5. 不建议采纳的点（诚实）

- **LPH 水印 / 10 字符转义**：安全 0，体积 +74KB 载体仅 32 命中，性价比极低；
- **解释器明文**：反面教材，坚决不回退；
- **纯 `v-v==0` 谓词**：已被探针钥匙化替代，回退是降级。
