# R064 v15 变量名压缩

> 日期：2026-10-06

根据当前要求，v15/默认 VM 输出中的生成局部变量、函数参数和循环变量使用最多两个英文字母；保留单字母名以避免无谓增加字节。名称分配器按 Lua 词法作用域回收名字：活动祖先作用域和全局名保留，互不重叠的函数/分支可复用短名，避免大型模板耗尽全局名字池。局部变量使用符号 ID 重命名，table 字段键和标准库 API 名不改，以免破坏语义。

R064 样本（固定 seed `64064`）的本地对比。上传源码里两处 `Color3.fromHex "..."` 的 Luau 调用简写在临时输入副本中改为等价的 `Color3.fromHex("...")`，以兼容本项目解析器；原文件未复制或修改：

- 旧产物：538,095 字节
- 新产物：499,521 字节
- 减少：38,574 字节，约 7.2%
- 新产物 Luau 语法编译通过；静态扫描 7,885 个局部/参数/循环变量标识符，未发现超过两个字母的名字。

实现由 `mangle_v15_compact` 完成，并在 v15 interpreter 与最终 shell 两次 AST 解析后应用。若一个词法作用域本身耗尽短名池，构建会明确失败，而不会静默退回长名称或生成冲突名。
