# 新反调试候选研究计划（研究日期 2026-10-09）

## 用户约束

1. 研究目前没有的机制；不把已有机制换名字充当创新。
2. “加入后强度不倒退”是待验证的入选门槛，不是实验前能保证的结论。
3. 多做可复现实验，包含攻击对照、合法语义、资源代价和反例。
4. 本轮不改现役引擎、服务、既有测试、示例或文档。仅在本目录新增研究工件；`.tools` / `target` 为重建工具与编译产物。
5. 按约五小时实验预算规划；以实际单调时钟耗时和已完成次数报告，不通过 sleep 填满时长，不将后台任务的计划算成完成。

## 范围与威胁模型

- 项目是纯离线 Luau VM。攻击者可读/改交付文件，强攻击者可观察同进程局部状态。
- 分别考察：只读观察、局部状态篡改、重放/跨帧错投、控制流跳转篡改、全部状态读取/恢复。
- 静态结构相似分、检查数量、trace 长度都不等于“安全强度”。
- 不针对安全软件、沙箱产品或某个执行器名称；不添加反安全工具黑名单。
- 独立 Python/Luau 模型不是正式 VM 集成；外层 adapter 的兼容结果不能证明在内部各调用点植入后仍兼容。

## 本轮独立候选

### C1：调用完成凭证（一次消费 + 帧所有权 + 阶段顺序）

只保护本 VM 自己的 CALL→POSTCALL 交接，不以宿主 API 的不稳定输出判定调试器。研究重点是旧完成事件重放、跨帧错投、重复完成；不同于现有 block decode epoch，它约束一次调用的阶段推进。

先验风险：新中央 wrapper/adapter 钩点；额外 pcall 改调用栈与错误位置；错误/yield 路径清理；对象分配；全状态观察者能取走当前合法凭证。属于执行完整性候选，不保证探测只读 debugger。

### C2：控制流边见证（合法边 + 独立预期 PC）

先用微型状态机验证非法跳边、丢步、重复事件能否被拒绝；测试合法边内的错误选择、数据修改和状态回滚能否绕过。

先验风险：显式 CFG 表帮助逆向；从同一个被篡改 PC 生成并验证见证是自证循环；伪造代数见证；分支条件含用户代码/元方法时不可重复求值。

### C3：数值见证/双轨冗余的可行性过滤

研究 Lua double 的精确整数边界、模乘实现、线性校验碰撞；检验通用数值恒等式对 NaN/inf/大数/元方法的副作用。

先验风险：线性校验不是 MAC；双轨执行用户运算会重复副作用，不能作为通用反调试；显式算术关系可能泄露原指令语义。

## 实验分层

1. **不变性**：开工记录 353 个现有文件 SHA-256；每轮结束复核，不修改产物基线。
2. **现役基线**：构建、cargo 测试、主/预设矩阵，记录退出码与耗时；真实 executor 无法在此验证。
3. **独立模型**：随机生成合法状态轨迹、注入局部故障、构造自适应绕过；同时记录拒绝和未拒绝，不只选正结果。
4. **Luau 行为**：尾 nil、多返回、错误对象、协程交错/yield、重入、调用栈、浮点、元方法、副作用与资源耗时。
5. **真实产物只读 A/B**：运行未经修改的 obsucvim；候选仅在外部研究 harness 中包裹可信语料/产物，验证边界行为和代价。不能称为候选已集成引擎。
6. **长跑**：以不同随机种子复现 baseline/wrapper 比较，逐条写 CSV，临时目标只保留一轮；失败保留有界样本。进程可被停止，重启不自动续算旧任务。到预算时输出最终统计，不进行无意义等待。

## 不倒退门槛

- 现有保护链全部保留，关闭候选后逐字节与基线一致（本轮不集成，尚不能证明集成后的关闭路径）。
- 无新增统一 handler/getter、完整明文表、长期缓存、失败 fallback 或外部信任根。
- 对声明覆盖的篡改有对照收益；不能仅仅检测自己的人造错误。
- 合法语义、错误对象/行号、元方法次数、协程、内存/时间预算等任何一项出问题即不推荐默认上线。
- 零误报样本只报告样本内结果；相关测试不能机械套用独立伯努利置信界。
- 必须区分“入围进一步集成实验”和“已证明不倒退”。预计本轮可淘汰不合格路线，不保证一定找到可上线方案。
