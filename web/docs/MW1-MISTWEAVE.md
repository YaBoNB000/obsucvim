2026-10-25 新指令立的**第二个全新自研技术**（同一指令重申执行）：目标 =
大幅抬高破解成本、强化抗解混淆；调研 → 设计 → 自命名 → 实现 → 门禁 →

**源码 → MW-1 → 引擎 R079 VM**（曾有的可选 PW-1 载体层已于 2026-10-25

## 1. 命名与定位

- 技术名：**雾织（MistWeave）**，版本 **MW-1**。
- 三模块：**雾锁 Foglock**（整数恒等不透明门族）、**雾织 Weave**
  （雾点插入纪律：只增不改）、**雾数 Fognum**（字面量恒等链）。
- 定位：输入侧变换。引擎 R079 本体不动；独立于 P 系收摊令（曾正交的 PW-1
  载体层已于 2026-10-25 撤销删除）。

## 3. 设计（MW-1 变换器）

### 雾锁 Foglock——整数恒等不透明门族（审计器逐点实锤）

- 永假：`x(x+1)≡0 (mod 2)` 判奇；`x²%4∈{0,1}` 判 2/3；`(x%3)²%3∈{0,1}` 判 2；
  `x·5k%5≡0` 判 1..4；`x+x+1` 恒奇判偶……永假支裹**幻体**（伪配置/伪解码/
  伪遥测/伪校验表——似真而不执行）。
- 永真：对偶族，支内裹**纯噪执行体**（无害算术链）——动态 trace 污染。
- 比例 7:3（假:真）。全部运算 < 2^53 整数模加乘/模比较，**逐位定论跨实现**
  （Lua 5.1/5.3/Luau/真 Delta double 域零漂移——R079/P1 纪律内化）。

### 雾织 Weave——只增不改插入纪律

- 插入点 = chunk 顶（雾局部声明 + 雾块）与各 `function(…)` 体顶。
- 新名一律 `_mwXXXXXXX` 唯一池；**绝不改写任何用户标识符/结构**——
  闭包/upvalue/method 语义零接触（实操雷区：作用域包裹会改 local 可见性，
  MW-1 全案不做区域包裹）。
- 词法器子集：ws/comment/str（短/长/反勾）/num/name/kw/op（含 Luau 复合
  赋值、`::`、`->`、`//`、`..=` 等）；长串与反勾串整体不透明（内部数字不雾）。

### 雾数 Fognum——字面量恒等链

- 纯十进制整数 0..10⁶ 按概率（默认 0.55）→ 乘法掩码族 `((c·a+b)−b)/a`
  （乘积 « 2^53 ⇒ double 精确整除）；0.35 概率联锁雾局部加深，0.30 概率
  二级梯加深。宏集数字/十六进制/浮点/科学计数一律不碰。

## 4. 门禁（`mistweave-selftest.py`，纯净 luau=唯一口径）

**11/11 全绿（2026-10-25）**：6 语料（递归/闭包/串表/循环/方法/混合字面量）

## 5. 诚实边界

- 静态抗剥：MW-1 的永假门族本身是**静态可证**（SMT/模式匹配可剥）——此为
  设计内已知边界；强度在装配：门与幻体被 R079 编译成方言随机 VM 字节码块
  后，剥离须先完成整个虚拟化逆向（入口即 P1 辩题域）。
- 体积：默认密度下 bind 件 203–206KB（微超 180–200KB 旧预算；
  `--num-fog 0.3 --blocks 3` 可压回带内——取舍归签发侧）。
- ~~与 PW-1 的关系~~：PW-1 已于 2026-10-25 定性纸老虎撤销删除；现役形态 =
  MW-1 攻静态/CFG 侧成本 + 引擎 R079 扛运行时/真实钥层，双层非同质轴。
