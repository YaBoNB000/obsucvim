## 1. 命名与定位

- 技术名：**径织（PathWeave）**，版本 **PW-1**。
- 三模块：**径锁 Pathlock**（执行期环境形制 + 帧内完整性锁的选道解密）、
  **幻径 Mirage**（诱饵车道静默失步 + 幻觉程序输出）、**织构 Weave**
  （生成器确定性 + 加密同质外观编织）。
- 定位：**引擎外载体层**（包裹任意已混淆交付件），引擎本体（R079）不动；
  独立于已收摊的 P 系台账，不复活任何被取消项。

## 3. 设计（PW-1 载体）

```
径织件 = 装载器（探针电池 + 选道 + 解密 + 完整性裁决）+ N 条车道密文
        （车道 1 = 真实载荷帧；车道 2..N = 幻径诱饵程序）
```

- **探针电池（8 项，全为跨实现逐位定论的形制检查）**：`game` userdata 形制、
  `identifyexecutor()=="Delta"`、`checkcaller` 存在、`error("x",0)` 返回形制
  恒等、`tostring(function)` 地址前缀、Vector3.new、task.spawn、
  tostring 常量词。真环境 ⇒ 电池=255 唯一车道 1；任意环境漂移 ⇒ 幻径。
  **纪律（P1 教训内化）**：禁浮点折叠/时钟量化/位运算；只用 <2^53 整数
  模加乘与 string/table 原语——Luau 5.1/0.6xx/0.7xx/真 Delta 语义逐位一致。
- **径锁**：真实载荷帧 `PW01 | djb2(payload) u32 | payload`，加法流
  （LCG 48271，key=r%251）加密 + 定制 base85（85 字符免转义 alphabet，
  4B→5B）入串。字节篡改 ⇒ 帧校验失败 ⇒ 幻径（**静默**，不外露）。
- **幻径**：诱饵为种子化生成的似真程序（伪斐波那契/伪心跳/伪配置/伪装配/
  伪校验五族），与真实载荷同质加密同 alphabet——静态侧各车道外观不可分。
- **织构**：同种子逐字节恒等（门禁实锤）；异种子 = 全新诱饵与密文布局。
- 密钥钩子：门闸读宿主 `identifyexecutor` 与 `os.clock` 路径（保持惰性，
  非真值不进钥流——避免 CLK 前科名不副实问题；PW-1 现版未用时钟）。

## 4. 否决分支（诚实记录）

| 候选 | 否决原因 |
|---|---|
| 时钟纠缠车道（os.clock 量化选道） | 真机设备速度多样性 → 慢速真设备会被误杀进幻径（可用性红线不可碰）；援引 CLK 守门惰性前科一并弃 |
| MBA/浮点折叠谓词 | P1 真机定罪过：折叠链在真 Delta double 相位失步；且 SMT/学习工具已压制该层 |
| 运行期 loadstring 自改密（metamorphism） | Luau 字节级自改需二段汇编，钩子面反而扩大；收益低于复杂度 |

## 5. 门禁（`pathweave-selftest.py`，纯净 luau=唯一口径）

**11/11 全绿（2026-10-25）**：基件 fib；同种子双包逐字节恒等；异种子必异；
真车道（Delta 形制桩）真 fib；裸 luau 幻径静默（exit 0 无报错文案）；
5 项探针单点翻转判别全部独落幻径；密文字节篡改 → 幻径；
体积打印（×1.267）。

## 6. 诚实边界

- **PW-1 不创造白盒秘密**：一个能对目标环境做逐位完美仿真（含 8 项形制、
  字符串地址前缀等）的静态/动态攻击者仍可逐层推到真载荷——脚本无外部机密
  的本质决定。PW-1 的真实增益是：① 自动化管线（envlog/--no-devirt 型）
  默认收割幻觉且无法察觉被欺骗；② trap-绞杀循环绞出的全是诱饵分支；
  ③ 字节篡改静默失步；④ 与引擎 R079（EVKEY 真钥层 + exguard + R5-b 链）
  叠加后，**双钥双闸**：扛得住静态的层扛模拟，扛得住模拟的层扛静态。
- 非真环境行为语义 = 静默幻径（与引擎「非真环境投毒、缺 API 干净拒绝」
  信条同族：不报错、不提示被识破）。
- 载体系数 ×1.267：bind 验收件 ~224–226KB 微超旧 180–200KB 预算
  （PW-1 为可选外层，启用与否归签发侧）。rustc 通道恢复后可将 PW-1
  内并入引擎模板（届时重新评估体积与锚点）。
